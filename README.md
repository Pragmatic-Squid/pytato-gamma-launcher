# pytato-gamma-launcher

**This is very much a work-in-progress!**

## What is this?
This is a lightweight recreation of the original S.T.A.L.K.E.R. GAMMA modpack launcher intended to allow low end devices to play GAMMA.
The launcher will install only the most necessary mods and leaves out any mods that are either to big in size or to heavy on performance like shaders and HD textures.


## How is progress?
I have created a modified modlist, that already filtered out most of the performance and storage heavy mods.
pytato-gamma-launcher can already successfully download all mods. Installation is not working 100%, though.

## What needs to be done?
Right now, there isn't much else pytato-gamma-launcher can do besides downloading the mods and extracting them with a success rate of about 80% (guessed).
